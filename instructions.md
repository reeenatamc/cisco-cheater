PASO 1: DESCOMPRIMIR LA EXTENSION
==================================
- Descarga el archivo .zip que viene adjunto en este correo
- Haz clic derecho sobre el archivo y selecciona "Extraer todo" (Windows) o simplemente doble clic (Mac)
- Te quedara una carpeta con los archivos de la extension. Recuerda donde la guardaste


PASO 2: INSTALAR EN CHROME
============================
- Abre Google Chrome
- Escribe en la barra de direcciones: chrome://extensions
- Activa el "Modo de desarrollador" (interruptor arriba a la derecha)
- Haz clic en "Cargar descomprimida" (boton arriba a la izquierda)
- Selecciona la carpeta que descomprimiste en el paso 1
- La extension aparecera en tu barra de extensiones (icono de puzzle arriba a la derecha)


PASO 3: ACTIVAR CON TU CLAVE
==============================
- Haz clic en el icono de la extension
- Pega tu clave de activacion (la de arriba)
- Dale a "Activar"


PASO 4: CONFIGURAR TU API KEY DE GEMINI (importante)
=====================================================
La extension usa Google Gemini como respaldo cuando no encuentra la respuesta en la base de datos.
Para esto necesitas tu propia API key gratuita de Gemini:

- Ve a: https://aistudio.google.com/apikey
- Inicia sesion con tu cuenta de Google
- Haz clic en "Create API Key"
- Copia la API key que te genera
- Abrre la extension y pegala en el campo "Gemini API Key"

Esto es gratis. Google te da un limite generoso para uso personal.


COMO USAR
==========
Tienes dos modos:

MODO TEXTO: Selecciona el texto de la pregunta en el examen, haz clic derecho y usa la extension. Busca la respuesta en la base de datos.

MODO CAPTURA: Toma un screenshot de la pregunta. La extension extrae el texto automaticamente con OCR y busca la respuesta. Si no la encuentra en la base de datos, consulta a Gemini.
